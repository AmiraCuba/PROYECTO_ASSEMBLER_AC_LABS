# Snake 8086

Juego de la serpiente desarrollado en lenguaje ensamblador para la arquitectura x86 (8086) en modo real.

## Estructura

```text
├── .gitignore
├── README.md
└── src/
    ├── main.asm
    ├── datos.inc
    ├── input.asm
    ├── logica.asm
    └── render.asm
```

## Compilación y Ejecución

1. Abrir `src/main.asm` en emu8086 o compilar con MASM/TASM en DOSBox.
2. Ensamblar y ejecutar.
